# 科技公司命名研究

为持续学习与出厂后智能强化方向的 AI Lab 研究中文为主的中英文品牌名。研究结果供合伙人讨论，公开搜索没有命中不等于工商或商标可注册。

## 从这里开始

- [初始研究材料与完整表格](research/seed/brand-naming-foundation.md)：105组背景案例的入口，供后续案例研究使用；[版本说明](research/seed/README.md)。

- [第一轮试跑结果](research/runs/2026-11-06/README.md)：本轮留下什么、为什么留下、还有什么不足。
- [完整研究报告 HTML](research/runs/2026-11-06/report.html)：下载后用浏览器打开；GitHub 文件页显示源码。
- [四 Agent 工作流程](docs/workflow.md)：案例、素材、中文创造、占用审核、英文匹配与复查。
- [历史研究资料](research/background/)：已有品牌与早期草案的背景存档；其中的草案不是当前推荐，也不算每日新增。

## 当前进度

已完成一次人工编排的四 Agent 试跑。12 个品牌案例、12 张素材卡、24 个字面草案，保守合并为 12 个创意家族；2 组完成中英文公开使用初筛，但尚未达到可直接定名的质量。

当前没有启用每日任务，也没有部署无人值守 Agent 系统。每天 20 个独立创意是后续目标，质量不足时如实报告缺额。

## 如何共同审阅

从 [本轮审阅 Issue](https://github.com/3013038780-design/Namingacompany/issues/1) 开始，或在 Issues 创建「名字反馈」，写明名字、喜欢或不喜欢的原因，以及读音、画面、行业气质方面的感受。同一家族的换字、同一中文的多种英文都归入同一条候选，不重复计数。

研究更新通过 PR 提交；先审阅结果，再决定合并。所有新候选保留来源、释义、短板与筛查证据。

## 本地校验

```sh
python3 scripts/validate_research.py
python3 research/runs/2026-11-06/render_report.py
```

数据文件、素材及代码保存在仓库中；运行校验不需要 API Key。外部资料的版权归各来源所有，仓库只存研究摘要与链接。
