# 分身有别 · Branchwise：英文首次返工

实际执行 `/root/continuous_a4`。以下仅为未经过英文使用查重的质量提案，数字自评另档。

- **建议读法**：BRANCH-wise，/ˈbræntʃ.waɪz/，两个音节。
- **真实构词**：branch（分支）+ -wise（以某种方式、就某个方面而言）。这里是按分支分别看待状态，不是branch加形容词wise聪明；已实际核词典后缀义。可自然理解的构形不等于本次证明Branchwise为词典独立词条，也不称它是COW专名。
- **中英文关系**：中文的同源分身对应从共同起点分出的分支，有别对应各分支对相关内存状态分别改写。英文从“按分支各自处理”的角度讲同一个共享与私有共存关系，而不只强调多出几个分支。
- **承载故事**：共同的起点，不必是一份永远同步改动的状态。名字把分叉后的主体当作应分别对待的研究对象，容纳共享底座与不同状态并存的AI研究；它说研究的视角，不说分支多了就更聪明。
- **短板**：可能首先像版本控制、分支管理或组织分部软件；单词branch本身不保证私有写入，-wise也不自动编码COW条件，需要来源解释。独立称呼较自然但技术描述感仍在。有人也会直觉把wise误读成聪明，必须明确不靠那层好寓意支撑。
- **事实边界**：分支是对fork过程的品牌转用，不能把所有树分支、Git分支与进程内存语义混同。-wise的方式/方面义有词典依据，但按分支处理不构成资源全面隔离的定理；只读页仍共享，文件描述符可共享open file description。不是逐字翻译或性能增长承诺。
- **本人实际阅读**：本人前案已实读MIT COW正文8–16与44–56行，Linux fork(2)正文25–42、99–122及194–199行；本次复核主控旧稿质量退回，另实际打开Merriam-Webster -wise所在词条153–181行，确认方式、方向与方面义。没有重新跑系统调用实验或使用查询。
