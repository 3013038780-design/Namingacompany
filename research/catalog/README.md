## 更新方式

每有合格新增，将来源文件登记到sources.json，并写清classification.json主分类和交叉理由，再运行 `python3 scripts/build_catalog.py`。只显式汇入终审通过或清楚标为储备的条目；不能扫描所有草案自动推荐。稳定编号按来源登记顺序分配，既有来源顺序与条目顺序不改；撤回保留原编号及原因，不删除后重编号。后续如有同一家族新英文，以同一总库ID记录版本，不新增一条。

总库更新不改原始轮次快照；新的审美或查重结论追加到revisions.json，保留日期、前后状态、理由和复核证据哈希。自动任务接续同一队列和现有PR，不因跨日或达到20结束。
