## 主要研究发现

**名称通常在第一层提供可辨识的声音或形象，在第二层建立真实的知识联系。** Codex连接代码与书册，Sakana连接鱼群与集体行为，日行迹连接天文轨迹与长期观察。名字的独立辨识与背景故事共同工作。

**同一研究方向可以采用完全不同的命名语言。** 自我改进和持续学习团队中，既有Recursive这样的技术机制，也有After这样的时间词、Plastic这样的物态性质，以及Mirendil、Ndea这样的自定义词或构词。研究定位并不要求名称直接复述技术功能。

**中文与英文可以同义、同音、同意象，也可以分层。** 日行迹/Analemma指同一个天文对象；大疆/DJI采用中文品牌与缩写；月之暗面/Moonshot AI共享探索主题，Kimi承担产品识别。

**好的来源也会被重复使用。** Mobius、Engram、Lambda、Axiom等已进入相关科技商业语境。研究名字的出处时，需要同步查看实际使用和权利证据；公司登记、产品使用与商标注册是不同结论。

本报告的重心是现有品牌研究与证据整理。案例间的交叉点用于启发讨论，不将其改写为新公司名称方案。

# 二 证据与范围

## 怎么区分事实和解释

下文使用三种口径：

- **官方解释**：企业、创始人、实际命名顾问直接说明名字的由来。

- **词义或技术事实**：词本身的含义、科学概念、中文与英文的对应关系能够确认，但不据此推断创始人的真实动机。

- **本报告分析**：对联想、声音、结构、传播效果的判断。

例如：“Anthropic 是与人有关的形容词”是词义事实；“公司一定以人择原理命名”则需要额外证据。查到公司经营 AI，也不能据此把它算作已经实现 RSI 的公司。

## 样本边界

广泛科技案例包括17个公司品牌及盘古模型，AI市场图谱按研究路径组织。公司、内部研究品牌、模型与产品分别注明；同一名称的中英文及常用拼写变体合并统计。

RSI与AI研究市场图谱包含62个公司、研究品牌及机构样本，覆盖自我改进、持续学习、记忆、自动科研、世界模型、专业研究与基础设施。公开定位和技术目标不等于已实现通用RSI；样本用于命名研究与市场比较，不声称穷尽未公开团队。

登记部分记录实际查到的司法辖区和证据。英国公开登记容易核验，因此英国样本较多；这不代表它们都是各词最知名的公司，也不代表与美国、印度等地同名品牌属于同一集团。

“存续 / 注销”以链接所展示的记录为准；网页或搜索索引可能有缓存，不能替代交易时取得的最新登记证明。

# 四 它们有哪些共性

## 1 八种命名来源

| 类型 | 案例 | 真正的交叉点 | 可归纳的命名特点 |
| --- | --- | --- | --- |
| 数学与计算概念 | MiniMax、Google、Recursive | 抽象系统的结构或尺度，与企业研究方向相遇 | 要保留完整概念的力量，避免只是看起来“懂数学” |
| 科学史与阶段 | 寒武纪、第四范式 | 过去的重大变化，表达未来的时代判断 | 能承载长期机构愿景，不被一个产品功能困住 |
| 人物与科学谱系 | Tesla；Claude 的人名形式 | 人物能让复杂领域变得可称呼 | 选择须考虑全球已有品牌、发音与文化负担 |
| 文学 神话与历史 | 百度、阿里巴巴、盘古、商汤 | 文化记忆与企业行为或愿景互相照应 | 典故先成为自然的词，再成为解释；无需占据大部分候选 |
| 自然系统 | Sakana | 群体、自组织、适应等机制成为研究隐喻 | 不只盯着宏大宇宙名，普通生命也可有强思想内核 |
| 日常词的语义迁移 | Reflection、Atlas、Codex | 人们已有的理解转移到新技术 | 首次接触能理解，深入解释又有内容 |
| 价值与使命 | OpenAI、Safe Superintelligence | 直接表达研究立场或目标 | 好名字可以清楚直白，但不要夸大已实现能力 |
| 声音与形象组合 | Kimi、TikTok、ByteDance | 口头传播、节奏、画面支撑记忆 | 音感不是装饰，它决定别人会不会主动使用名字 |

这些类别会重叠。Codex 同时属于既有词迁移、知识史和声音关联，不应强行只贴一个标签。

## 2 六种中英文关系

| 关系 | 案例 | 应如何评估 |
| --- | --- | --- |
| 拼音 | 百度 / Baidu、盘古 / Pangu | 保留中文身份；检验外国人能否读、能否拼 |
| 音译及声音适配 | Tesla / 特斯拉、Google / 谷歌、NVIDIA / 英伟达 | 两种语言各自自然，避免硬凑每个字的意义 |
| 语义对应 | 深度求索 / DeepSeek、第四范式 / 4Paradigm | 同一个核心概念，两边不必等长 |
| 同意象的灵活转写 | 字节跳动 / ByteDance | 允许动词、语序变化，保留画面 |
| 主题呼应的独立名字 | 月之暗面 / Moonshot AI、商汤 / SenseTime | 必须能用一句话解释关系，但不必字字对应 |
| 中文与缩写配合 | 大疆 / DJI | 中文与英文承担不同传播任务，核查缩写是否已过度拥挤 |

**先找到一边成立的名字，再测试另一边，通常比同时造两个名字更可靠。** 但国际实验室不能等中文完全定案后才发现英文很难念或直接撞上同业。

## 3 什么不能从案例中推出

这些公司没有共同遵守“两个字”“必须古文”“必须包含 AI”“必须全球无人使用”等规则。成功名字也不总是语义精准：Google 有拼写变化，Anthropic 有理解门槛，OpenAI 带有明确价值承诺。我们应学它们解决了什么问题，而不是抄它们的外形。

## 命名共性的综合观察

这些团队共同关心智能如何形成或改进，采用的名字却覆盖多种语言结构。Recursive直接命名机制；After、Plastic、Trajectory借普通词连接时间、可塑性与经验；Mirendil、Ndea通过自定义释义或构词建立身份；日行迹、Sakana借完整的自然对象；Imbue、Inherent、Ineffable则表达对智能或研究的看法。

| 共性 | 代表案例 | 研究结论 |
| --- | --- | --- |
| 一个名字连接两个世界 | Sakana、Codex、日行迹、Hume | 日常、自然、历史或人物思想与研究方向发生关系；业务解释不必全部写在字面上 |
| 第一层可称呼 第二层可解释 | Imbue、Mirendil、Google、Kimi | 声音和词形负责识别，出处提供进一步记忆；典故并不替代使用体验 |
| 完整概念优于任意拆字 | MiniMax、第四范式、Discovery Loop | 概念内本来就有关系，解释不依赖事后给每个字分配寓意 |
| 公司 产品 研究品牌分层 | Moonshot AI与Kimi、Anthropic与Claude Code、Mind Lab与Macaron | 机构表达世界观，产品可以更亲近或具体；两层不必采用同一命名方式 |
| 双语关系有多种成立方式 | 日行迹/Analemma、大疆/DJI、自变量/X Square、月之暗面/Moonshot | 可采用同义、拼音、缩写或主题呼应，关键是两种语言各自成立 |
| 同业拥挤改变辨识成本 | Mobius、Engram、Lambda、Axiom | 好出处也会反复被想到，必须同时查看实际商业使用及权利证据 |

| **MaxMin** | 与 max–min 优化有关；标准术语常写 maximin，不能把任意 MaxMin 写法当作一项独立算法。 | 极值顺序与视觉对称。 | 与 MiniMax 太近，倒序不能产生足够独立身份；不优先。 |

## 对“能不能用”的准确回答

现有证据可以确认相关概念已有商业或项目使用，不能替代中国大陆公司核名及商标可注册性核查。境外公司记录、国内公司登记与商品服务商标分别记录。

| **Imbue**：[实际改名过程](https://www.ahundredmonkeys.com/case-study/imbue/) | “赋予、使充满”的既有动词 | 赋予机器智能与人类价值 | 动词可以承载研究使命，同时保留温度和可称呼性 |
| **Ndea**：[公司自述](https://ndea.com/) | idea的声音及直觉、逻辑的思想概念 | 深度学习与程序合成相接 | 构词有实际依据，声音和含义共同形成完整品牌 |
| **Mirendil**：[官网释义](https://mirendil.com/) | 与隐藏珍宝、未知发现为友 | 发现的价值与自主科研相接 | 机构名称表达世界观，具体技术路线放在品牌说明中 |
| **日行迹 / Analemma**：[公司关联报道](https://www.36kr.com/p/3680086801936003)与[科研机构发布](https://www.sii.edu.cn/2026/0304/c27a761/page.htm) | 太阳一年中在固定观测条件下形成的轨迹 | 天文学、循环形态、长期观察与科研相接 | 三字中文与既有英文共享同一真实对象 |
| **Sakana AI**：[官方说明](https://sakana.ai/series-a/) | 鱼及鱼群 | 简单局部行为与集体智能相接 | 日常事物可以具有机制深度，名字不必冷僻 |
| **第四范式 / 4Paradigm**：[原始思想资料](https://www.microsoft.com/en-us/research/wp-content/uploads/2009/10/Fourth_Paradigm.pdf)与[创始人访谈](https://www.nbd.com.cn/articles/2024-08-13/3503085.html) | 数据密集型科学发现范式 | 科学史阶段与企业愿景相接 | 一个完整概念可自然承载四字中文及英文数字品牌 |
| **Google / 谷歌**：[官方历史](https://about.google/company-info/our-story/) | googol及其拼写变化 | 数学尺度与信息组织相接 | 轻微变化使学科词成为独立品牌，中文再做声音和形象适配 |
| **月之暗面 / Moonshot AI / Kimi**：[公司产品官网](https://www.kimi.com/)及[文化关联报道](https://www.36kr.com/p/3163281487412745) | 未知区域、宏大挑战、简短产品称呼 | 机构的探索意象与产品的亲近感分工 | 公司和产品可以使用不同的命名语言 |
| **大疆 / DJI**：[官方解释](https://www.dji.com/pt/newsroom/news/dji-opens-new-headquarters-for-creative-community-in-the-sky) | 广阔边界与创新 | 空间意象与工程创新相接 | 中文具有画面，英文以缩写承担国际传播 |

从这些案例可以归纳出五项共同观察：名称具有独立可称呼性；出处与研究主张之间存在可说明的关系；中英文各自适应语言；机构与产品层级清晰；实际使用空间影响辨识成本。这些观察适合用于比较现有名字，不能单凭某一项证明品牌会成功。

# 十 书籍方法的支撑与阅读范围

书籍与作者公开资料提供命名分析框架。下表明确列出实际参考范围，公开试读、演示资料与配套工具不等同于完整通读。

| 资料 | 本次检索实际参考范围 | 用在本报告中的结论 |
| --- | --- | --- |
| Rob Meyerson，**Brand Naming** | [出版社公开试读](https://www.businessexpertpress.com/wp-content/uploads/2022/09/9781637421550.pdf)，非全书 | 把战略、创意与实际可用性同时考虑；不能先拼出一个解释过满的词，再靠故事补救 |
| Marty Neumeier，**The Brand Gap** | [作者公开演示资料](https://www.martyneumeier.com/s/the-brand-gap-14630.pdf)，非全书 | 独特、简短、适合、易读写、可延展等需要一起看；辨识度不等于描述完整度 |
| Alexandra Watkins，**Hello My Name Is Awesome** 的配套方法 | [作者命名评估工具](https://eatmywords.com/free-name-evaluation-test/)，非全书 | 注意画面、情感、传播及拼写解释负担；不因学术出处而忽略使用体验 |
| **The Fourth Paradigm** | [微软研究院公开原书](https://www.microsoft.com/en-us/research/wp-content/uploads/2009/10/Fourth_Paradigm.pdf)的命名相关引介，非全书研究综述 | 验证“第四范式”是已有思想概念，不是为了公司临时制造的口号 |

书籍资料用于分析框架；公司命名由来与实际使用仍以企业、创始人、命名顾问、研究机构、登记机关等具体来源为依据。
