| **Manifold / 流形** | 数学中可在局部用较简单结构描述的空间。 | 把复杂整体与局部可理解性连接起来，英语本身也有多样、繁多的日常意味。 | [Manifold生命科学AI](https://www.manifold.ai/about)；[Manifold Labs](https://www.manifold.inc/) |
| **Attractor / 吸引子** | 动力系统长期演化趋向的结构。 | 像某种看不见但会组织行为的力量，容易形成运动与稳定形态的想象。 | [AttractorAI](https://www.attractorai.com/) |
| **Eidos / 形式 理念** | 希腊思想中的形式、理念等概念。 | 短、清楚、有哲学厚度，能把抽象认识转成一个独立专名。 | [Eidos AI](https://www.eidos.ai/) |
| **Praxis / 实践** | 源于希腊语的实践、行动概念，在哲学中经常与理论相对照。 | 不讲某种算法，而是讲知识进入行动；声音有力度，能容纳许多应用。 | [Praxis AI](https://praxis-ai.com/)；[Praxis物理工作平台](https://www.getpraxis.ai/) |
| **Second Nature / 第二天性** | 通过后天练习而变得自然、自如的能力。 | 这是一个已经被日常使用的完整表达，直接连接经验积累与能力内化。 | [Second Nature AI训练产品](https://secondnature.ai/wp-content/uploads/2023/05/1111111111.pdf) |
| **Palimpsest / 重写本** | 原文被擦除后再次书写、却仍可能留下旧痕迹的手稿。 | 把层叠、记忆、改写、残留同时放进一个文化对象，有非常具体的材质与时间感。 | [同名AI记忆项目](https://github.com/hicksonhaziel/Palimpsest) |
| **Axiom / 公理** | 建立一个推理体系时采用的基本起点。 | 短、完整、思想性强；从起点建立更大知识结构的故事自然成立。 | [Axiom Math](https://axiommath.ai/) |

Reflection、Harmonic、Integral、Inherent等既有英文词已在前面的公司案例中解释；此处与它们采用同一个观察方法：词的原义、跨领域联想，以及已经形成的商业使用。

# 五 名字背后的交叉点与共性

## 1 命名来源的十五类

这些类别是可交叉的观察角度，一个名字可以同时出现于几类。先看素材来自哪里，再看它怎样与业务、声音和日常经验连接；具体词源仍以各案例行的出处为准。

| 命名来源 | 报告案例与延伸素材 | 交叉点与品牌作用 |
| --- | --- | --- |
| 计算机世界的日常物件与界面 | Cursor、Runway；可继续研究Caret、Shell、Canvas | 每天见过的物件已有视觉与使用记忆。光标既是标记，也是落笔和行动的位置；跑道既是现实设施，也是起飞前的准备空间。Runway属于现实物件向数字创作的迁移。 |
| 信息与计算的基本组成 | ByteDance、零一万物、Intel | 字节、二进制、电子器件把复杂世界还原成简单构件。微小单位与巨大系统形成尺度反差；ByteDance再让静态字节有了跳动。 |
| 程序机制与系统构建 | Recursive、Ricursive、Quine、Bootstrap、ReLU、Softmax | 递归、自指、自举、激活等真实机制，本身就有行为或过程。圈内人获得学科认同，圈外人可以先把短词当作专名记住。 |
| 数学与逻辑原理 | MiniMax、Möbius、Lambda、Axiom、Lattice、Integral、百奥几何 | 优化、拓扑、演算、公理、格与几何提供真实的结构。专业含义之外，常有极值、连续、基础、整体等日常入口。 |
| 物理概念与材料 | 深势、硅基流动、Harmonic、晶泰 | 势、硅、谐波、晶体具有物质或数学依据。技术概念与能量、流动、和谐、秩序等可感联想相接。 |
| 自然力量与地球现象 | Mistral、Liquid AI、日行迹；火山引擎作为补充案例 | 风、液态、天体轨迹、火山各自带着运动规律。名字既能成为画面，也能借现象讲适应、时间积累、力量释放。 |
| 生物与演化现象 | Sakana、寒武纪、DarwinAI、字节Seed | 鱼群、生命爆发、演化和种子让人联想到局部互动、长期适应与生长。自然过程提供故事，品牌选择其中与研究呼应的一层。 |
| 日常事物与生活经验 | Apple、小米、Hugging Face | 水果、谷物、拥抱先建立亲近感和称呼习惯，技术企业由此获得温度。名字不必先解释业务，日后的产品为它增加意义。 |
| 地理空间与开阔意象 | Adobe、Cisco、Amazon、大疆、星海图 | 真实地理来源与空间意象都能给品牌尺度和方向。Adobe、Cisco有具体地名起点；大疆、星海图则可从疆域、星海与探索作意象解读，二者不混作同一种词源。 |
| 神话传说与文化角色 | Alibaba、盘古、Atlas、Oracle | 人物、故事与文化角色携带已有的情节和能力。一个词就能引出开启宝藏、开辟世界、承载或预见等叙事。Atlas也兼有地图集的词义。 |
| 文学艺术与知识载体 | 百度、月之暗面、Codex、Memento、晶泰XtalPi | 诗词、音乐、书册、记忆与电影提供第二层发现。品牌首先能被称呼，理解出处以后又增加情感与世界观。XtalPi的电影来源有公司直接解释。 |
| 科学人物与思想传统 | Tesla、Hume、Hopfield、Turing、Gödel、Kleene | 姓名把研究史与思想带入品牌。其力量来自人物实际贡献与团队认同，不需要把学者生平成段写进公司名。 |
| 时间阶段与探索旅程 | After、Midjourney、Trajectory、第四范式、星动纪元 | 之后、途中、轨迹、新范式与新纪元都把品牌放进一段过程。名字给出位置、方向或阶段，容得下继续发展。 |
| 认知情感与哲学概念 | Anthropic、Cognition、Perplexity、Reflection、Imbue、Noosphere | 人、认知、困惑、反思、赋予与集体思想让技术回到心智问题。普通词的多义性尤其有价值：Reflection同时连接光学与思考。 |
| 价值立场与研究愿景 | OpenAI、Safe Superintelligence、Thinking Machines Lab、Mirendil、Ineffable | 名字表达相信什么、想研究什么、怎样面对未知。可以直接陈述使命，也可以像Mirendil一样通过“发现的朋友”建立角色。 |

## 2 为什么这些名字好记

**先有可称呼的外壳，再有值得讲的第二层。** Kimi、Sony、Apple、Sakana都容易进入日常语言；知道出处以后，名字又增加一层内容。对专业词也是如此：Quine、Lambda、ReLU首先要能成为称呼，专业背景再提供认同感。

**交叉点应当原本存在。** Codex确实是书册，Reflection确实兼有反射与反思，Analemma确实是日行迹。名字不是先出现几个漂亮字，再为每个字各编一个理由。

**一个名字可以说出态度，也可以留出未知。** OpenAI表明立场，Midjourney表明仍在途中，Mirendil把自己放在发现的伙伴位置。它们提供的是持续可讲的故事。

## 3 中英文如何共同成立

| 关系 | 案例 | 名字之间怎样配合 |
| --- | --- | --- |
| 同一对象 | 日行迹 / Analemma、盘古 / Pangu | 一个真实概念或文化对象，在两种语言中保持同一身份 |
| 拼音或音译 | 百度 / Baidu、Tesla / 特斯拉、Sony / 索尼 | 保留可辨识的声音，让本地语言形成自然称呼 |
| 语义与画面对应 | 字节跳动 / ByteDance、硅基流动 / SiliconFlow | 两边都能看到同一个动作或形象 |
| 同主题的独立名字 | 月之暗面 / Moonshot AI、商汤 / SenseTime、超衍 / Apex | 不逐字相等，但讲述相容的世界观 |
| 中文与缩写 | 大疆 / DJI、智源 / BAAI | 两种语言分别追求适合自身传播的长度与结构 |
| 母品牌与产品分层 | Anthropic / Claude Code、Moonshot AI / Kimi、Anysphere / Cursor | 机构承载长期身份，产品承担日常称呼或具体入口 |

## 4 名字怎样组合

素材来源之外，还可以观察组成方式。一个自然词可以独立成立，也可以与另一个领域的词发生联系。

| 组成方式 | 案例 | 为什么成立 |
| --- | --- | --- |
| 熟词直接成为专名 | Apple、Cursor、Liquid、Reflection | 先借已有的读音、画面和语义，再由产品赋予新的身份。 |
| 两个领域彼此连接 | ByteDance、SiliconFlow、火山引擎、BioGeometry | 字节与跳动、硅与流动、自然力量与工程装置、生命与几何，各有可解释的连接。 |
| 既有过程或短语成为品牌 | Discovery Loop、Thinking Machines、Midjourney | 名字像一个本来就成立的说法，读者容易还原出行动、角色或场景。 |
| 有来源的变形与融合 | Google、Sony、Lenovo、XtalPi | 通过拼写或语素组合建立独特声音；出处和可称呼性共同工作。 |
| 中英文各自成立 | 月之暗面 / Moonshot AI、千寻 / Spirit AI、百奥几何 / BioGeometry | 可以共享主题、声音或对象；不必为了逐字对应牺牲某一种语言的自然程度。 |

## 5 火山引擎为什么能承载多层含义

火山引擎是字节跳动旗下的云服务平台，与抖音是同一集团下的不同品牌。[官方介绍](https://www.volcengine.com/about)

“火山引擎”把一个人人能想象的自然景象，与一个能输出能力的工程装置接在一起。以下为命名解读，非创始团队原意的转述。

| 含义层次 | 名字如何起作用 | 对AI Lab命名的启发 |
| --- | --- | --- |
| 视觉与情绪 | 火山有轮廓、颜色和喷发的动作；“火”在中文里又能表示热度与关注。 | 名字在解释之前，就可以先让人看见、感到某种东西。 |
| 自然过程 | 地下岩浆与压力积累，能够转为强烈的地表释放；不同喷发方式各有机制。[USGS说明](https://www.usgs.gov/faqs/how-do-volcanoes-erupt?page=1) | 寻找具有真实过程的意象：蓄积如何转成输出，微小变化怎样形成新能力。 |
| 工程角色 | 引擎把能量转成驱动力；对企业服务而言，也容易让人理解为“推动别人的业务”。 | 你们的角色是让其他模型获得继续成长的条件，名字可以讲这种赋能关系。 |
| 长期叙事 | “火山”提供力量与画面，“引擎”给出可使用的能力；日后可延伸到不同技术和场景。 | 用一个足够宽的意象容纳未来研究，不必把当前算法写进名字。 |

火山与引擎共享“能量成为驱动力”的关系，因此组合有内在理由。字节跳动也有同样的结构：信息单位获得运动与生命感。机械替换成“某某引擎”，并不会自动保留这种力量。

# 六 从持续成长的产品特点寻找名字

产品的核心命题是：**模型投入使用之后，仍能让经验留下来，并把经验转成下一次行动的能力。** 这包含经验输入、积累保留、能力转化、再次行动四层。品牌可以选择其中最有画面的一层，也可以通过一个自然过程同时承载几层。

| 产品特点 | 可寻找的真实世界过程 | 可以承载的故事 | 需要避开的误读 |
| --- | --- | --- | --- |
| 已有模型继续成长 | 树木形成层、分生组织、成年后的持续生长 | 已经成形，仍然保有长出新能力的地方。 | 只像育儿、学校或培训机构。 |
| 使用经验能够积累 | 年轮、痕迹、沉积、程序状态 | 过去的经历成为现在的一部分。 | 只记住历史，却不改变行动。 |
| 反馈转成下一次能力 | 自举、复利、实验循环 | 上一次获得的东西成为下一次的起点。 | 将循环误写成必然指数增长。 |
| 让不同模型获得增强 | 合流、连接、共同的生长条件 | 不同来路的能力与经验在此相接。 | 被理解成单纯的模型聚合或转发平台。 |
| 保留已有成果进入下一阶段 | 二周目、续延、第二次出发 | 带着过去继续，而非每次重新开始。 | 只像重启、复刻或重玩。 |

## 可以比较的六组命名草案

以下是基于真实概念的创意草案。中英文有的是主题配对，有的是术语对应；这些是待讨论的品牌表达，未据此认定名称可独占使用。

| 中文与英文 | 真实出处和配对关系 | 多层含义与产品联系 | 命名上的取舍 |
| --- | --- | --- | --- |
| **年轮 / Cambium** | 年轮是树木的生长记录；Cambium是形成层，参与木本植物的次生增粗。前者是可见记录，后者是持续生长的组织，属于同一生命过程中的主题配对。[林务局说明](https://research.fs.usda.gov/treesearch/38087) | 时间留下层次，环境影响生长，已有树干继续增加新组织。中文给画面，英文给生长机制。 | 中文自然好记；英文需要教一次发音。它强调长期积累，速度感较弱。 |
| **合流 / Confluence** | Confluence指河流汇合，也指事物的汇聚；中英文共享汇合意象。 | 不同模型、经验与反馈进入共同的成长过程；细流组成更大的水系，也有合作与开放的意味。 | 能容纳AI Lab的长期研究，但容易先被理解为聚合平台；Confluence已有广泛品牌使用。 |
| **生长点 / Meristem** | “生长点”对应植物生长区域的直观称呼；Meristem是分生组织的学术词，具体范围不完全等同。[大学植物组织学资料](https://mmegias.webs.uvigo.es/02-english/1-vegetal/guiada_v_meristemos.php) | 模型已经成形，却仍保留长出新能力的地方；可以联想到为已有模型增加成长条件。 | 三字容易说清产品思想，英文很有研究气质，但专业门槛高，中文也偏功能性。 |
| **回响 / Echo** | 回响是声音反射后再次被听见，Echo是对应常用词。 | 行动不会无痕消失：环境给出回应，经验重新进入系统。既有反馈结构，也有人与世界互相回应的情感。 | 声音和画面自然，但“回响”本身不包含学习；需要品牌叙事说明回应怎样变成改变。 |
| **复利 / Compound** | 复利的基本关系是既有收益进入后续计算；Compound另有组合、复合之义，中英文围绕积累与组合配对。 | 已有能力产生经验，经验成为下一阶段的资源；适合讲经验的长期价值。 | 中文很直观，但金融联想强；英文多义，声音也更硬。不能把它当作增长率承诺。 |
| **二周目 / New Game+** | 游戏中的新一轮流程；New Game+模式常允许继承部分已有成果，具体规则因游戏而异。 | 已有模型带着经验进入下一阶段。既讲第二次成长，又有文化记忆和一点玩味，能够承载出厂之后的故事。 | 中文已有明显记忆点；英文更像产品或功能名。重玩的意味需要与持续成长区分。 |

这六组各有侧重：年轮强调时间留下能力，合流强调多路经验相接，生长点强调保有成长机制，回响强调反馈，复利强调积累的再利用，二周目强调继承后的下一阶段。作为长期AI Lab品牌，优先比较年轮与合流的宽度；作为产品品牌，二周目的趣味和可称呼性值得保留。
