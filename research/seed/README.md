## 如何使用

Agent 1 应先读这份初始材料，按广义科技、本轮 AI、RSI 相关场域扩展案例，而不是只围绕首轮12个样本。分析沿用四个问题：词是什么意思、素材来自哪里、两个世界怎样交叉、为什么容易成为品牌。

“为什么好”与“承载的故事”属于命名分析；要作为命名事实使用的词源需打开一手来源复核，不能把历史报告直接升级为已核实证据。Agent 2 将共性用于寻找新素材与创作，不机械复制现有名字，不限定叠或其他字根。
